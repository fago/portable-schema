# Scope

| In | Out |
|---|---|
| The spec: profile and vocabulary | Runtime data objects, e.g. Drupal's Typed Data objects |
| A generic type library | Framework types (bundles, plugins, config types): generated by integrations |
| Conformance fixtures | Widget and form rendering implementations |
| Reference validators in PHP and JS | Forms, routes, access, saving: for example Data Surfaces |
| Normalization and coercion rules | A new standard, or an expression language |
| Result format and a shared message catalog | Supporting several JSON Schema drafts internally |
| Catalogs, registry resolution, the schema dump format | |
| Export to plain JSON Schema | |
