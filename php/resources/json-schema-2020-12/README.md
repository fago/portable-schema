# JSON Schema 2020-12 meta-schemas

The vocabulary meta-schemas of [JSON Schema 2020-12](https://json-schema.org/draft/2020-12), as published at `https://json-schema.org/draft/2020-12/meta/*`.

- Taken unchanged from `draft-2020-12/meta/*.js` of `@hyperjump/json-schema` 1.18.0, as JSON, so PHP checks schemas against the same meta-schemas as JS.
